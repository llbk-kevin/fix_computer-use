# 02 修复方案

目标是在保留现有系统的条件下恢复官方窗口截图，同时保留可回退的原版文件和可临时使用的桌面截图工具。已确认的故障点见 [故障背景与原因](01-故障背景与原因.md)，版本及操作步骤见 [使用与回退](03-使用与回退.md)。

## 原生兼容层

当前有效实现包含两处适配：

1. 跳过可选的关闭捕获边框操作，保持系统默认边框。
2. 将 `SoftwareBitmap` 的异步表面复制改为同步读取 WGC 提供的 D3D11 纹理，再生成位图，避免帧回调内的阻塞等待。

纹理读取经 staging texture 完成，按实际行跨度复制像素，生成 BGRA8 / Straight alpha 的 WinRT 位图，并返回已完成的 `IAsyncOperation`。这里仍使用真实捕获帧，后续窗口处理、JPEG 编码、截图 ID 和应用授权继续走官方链路。

兼容 DLL 局部包装 `SoftwareBitmap` 静态接口；其他 WinRT 激活请求交回系统。构建脚本对单一原程序哈希检查导入表和指令位置，再生成候选程序。安装脚本独立校验候选文件、完整备份原版并提供回退。当前实现不处理其他纹理格式，不据此声称支持 HDR。

实现入口：

- [兼容接口](../tools/wgc_compat.cpp) 与 [纹理读取](../tools/wgc_readback.h)。
- [构建脚本](../tools/build_wgc_compat.py)：只生成文件。
- [安装与回退脚本](../scripts/install-wgc-readback.ps1)：默认检查状态，显式选择安装或回退。

**已在指定版本、本机资源管理器场景验证原生截图恢复；其他版本和业务场景未据此获得验证。** 本地修改使辅助程序不再具有原版的有效厂商签名，精确状态和哈希见 [使用与回退](03-使用与回退.md)。

## 备用桌面截图

[备用工具](../tools/capture_screen.py) 使用 Pillow / Windows GDI 读取可见桌面，支持整屏、指定显示器和区域裁剪。它每次枚举显示器布局，处理负坐标与 DPI，并拒绝越界裁剪或覆盖已有输出。

| 能力 | 原生兼容层 | 备用桌面工具 |
| --- | --- | --- |
| 调用方式 | 官方 `sky.get_window_state` | 独立 Python 命令 |
| 图像来源 | WGC 捕获帧 | 当前可见桌面像素 |
| 官方截图 ID | 由官方链路返回 | 不提供 |
| 适用用途 | 恢复匹配版本的原生截图 | 临时取图或辅助核对 |
| 主要限制 | 精确版本匹配；本地修改后的签名状态 | 遮挡、最小化及受保护内容可能影响结果 |

备用工具不会自动修复官方接口，也不提供点击或输入功能。
