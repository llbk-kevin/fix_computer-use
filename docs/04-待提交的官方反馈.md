# 04 待提交的官方反馈

**状态：尚未向官方维护者提交。** 以下内容是根据已验证案例整理的反馈，未附真实桌面、应用业务内容或厂商二进制。

## 建议标题

Codex Computer Use on Windows 10 LTSC 2021: missing IsBorderRequired API and bitmap conversion timeout

## 环境与现象

- Windows 10 Enterprise LTSC 2021，21H2，19044.1620，x64；活动且解锁的桌面。
- Codex 26.915.4065.0，Computer Use 插件 26.915.31945，`@oai/sky` 0.7.1。完整运行时和原文件哈希见 [已验证配置](03-使用与回退.md#适用版本和依赖)。
- 普通资源管理器窗口即可复现。窗口枚举与 UI Automation 文本读取成功，原版截图失败。

## 最小复现

在提供 Computer Use 的官方 `node_repl` 会话中初始化并查看窗口列表：

```javascript
if (!globalThis.sky) {
  globalThis.sky = (await import("@oai/sky")).sky;
}
globalThis.windows = await sky.list_windows();
nodeRepl.write(JSON.stringify(windows, null, 2));
```

检查返回列表，在下一次调用中将唯一选中的真实资源管理器窗口对象设为 `targetWindow`，处理应用授权后执行：

```javascript
await sky.get_window_state({
  window: targetWindow,
  include_screenshot: true,
  include_text: false,
});
```

原版返回：

```text
SetIsBorderRequired failed: 不支持此接口 (0x80004002)
```

重新枚举并选择窗口后仍复现；同窗口关闭截图、开启文字读取则成功。WinRT 能力检测得到基础 WGC 存在且 `IsSupported() = true`，但 `IsBorderRequired` 和 `UniversalApiContract` v12 不存在。

## 后续阻断点与本地对照

在单一哈希版本上保留默认边框，缺失接口错误消失，但原生调用继续报 `FrameArrived timed out`。

独立 WGC 对照表明：有效捕获帧已经到达；在 `FrameArrived` 回调内同步等待 `SoftwareBitmap.CreateCopyFromSurfaceAsync` 会超时，将同一转换移到独立 MTA 线程则成功。同步读取 D3D11 staging texture、生成 BGRA8 / Straight alpha 位图也能成功。

本地兼容层同时处理这两点后，官方 `sky.get_window_state` 已通过资源管理器连续图文快照验收。该结果验证了本机补救路线，不代表厂商原版已经修复，也不推断所有系统或显示驱动都存在相同问题。[原理](02-修复方案.md) · [测试记录](Log/2026-09-21-修复记录.md)

## 预期行为与建议

1. 在运行时判断可选边框接口是否存在；旧系统保留默认边框，继续基本捕获。
2. 避免在帧回调内阻塞等待可能依赖回调返回的异步表面转换；将转换移出回调，或采用经过验证的像素读取方式。
3. 将捕获帧未到达与位图转换超时分别报告，便于定位问题。
4. 保留应用授权及无效窗口、设备丢失、访问拒绝等错误；在旧系统和支持新接口的系统分别验证行为。

当前缺少官方原生后端源码，因此这里提供本机实验和行为建议，不指认厂商源码行号。
