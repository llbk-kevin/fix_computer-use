## node_repl 的作用

`node_repl` 提供 JavaScript 执行环境。Windows Computer Use 通过它导入 `@oai/sky`，再调用窗口枚举、截图、文字读取及输入接口。MCP 管理器里的启用标记代表配置状态，是否能够执行还需要检查启动和实际调用结果。

**目前没有证据说明 CC Switch 造成了截图故障。** 服务能够启动、执行 JavaScript 和枚举窗口，而修复前错误发生在原生捕获链路；独立 WGC 对照又复现了表面转换等待问题。截图修复期间没有改动 CC Switch 数据库、Codex 配置或共享 Skill。

当前任务提供给模型的工具列表中未出现 `node_repl`，与已配置 MCP 服务能否运行是两个不同检查项。本轮没有确认工具列表缺项的应用侧原因，也没有通过修改配置声称修复了这一项。

配置中存在具体的 Codex 运行时目录和原生管道名。后续应用更新或运行环境变化时，应重新检查实际路径和连通性，不能仅凭管理器的启用标记判断它们仍有效。

## 只读复查

在项目目录执行：

```bat
python tools\diagnose_node_repl.py
```

[诊断脚本](../tools/diagnose_node_repl.py) 只做 MCP 初始化、JavaScript 测试与窗口数量读取，不修改配置、不输出环境变量值或窗口标题，也不自动批准应用访问。报告位于 `artifacts/diagnostics/node-repl-status.json`。

截图验收触发的 `Allow Codex to use explorer?` 是 Computer Use 自身的应用授权。用户在本轮已明确允许用于资源管理器诊断；该授权不等于允许任意应用、文件删除、移动或文字输入。
